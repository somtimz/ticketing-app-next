# E2E Test Suite Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Wire up a Playwright E2E suite that covers all major user flows across all four roles (Employee, Agent, TeamLead, Admin), running against the local dev server with the seeded database.

**Architecture:** Role-fixture approach — a single `globalSetup` file (`e2e/auth.setup.ts`) seeds the database and authenticates once per role, saving each browser session to `e2e/.auth/<role>.json`. Five Playwright projects (setup + one per role) load the saved sessions so no test ever visits the login page.

**Tech Stack:** Playwright `@playwright/test`, Chromium only, Next.js dev server started automatically.

**Design doc:** `docs/plans/2026-02-18-e2e-tests-design.md`

## Task 4: Create `e2e/auth.setup.ts`

**Files:**
- Create: `e2e/auth.setup.ts`

This file runs once as the `setup` project. It seeds the database, then logs in as each role in sequence, clearing cookies between logins, saving each session to `e2e/.auth/<role>.json`.

**Step 1: Create the file**

```typescript
// e2e/auth.setup.ts
import { test as setup } from '@playwright/test';
import { execSync } from 'child_process';
import path from 'path';

const AUTH_DIR = path.join('e2e', '.auth');

const USERS = [
  { role: 'employee', email: 'employee1@company.com', password: 'employee123' },
  { role: 'agent',    email: 'agent1@company.com',    password: 'agent123' },
  { role: 'teamlead', email: 'teamlead1@company.com', password: 'teamlead123' },
  { role: 'admin',    email: 'admin@company.com',     password: 'admin123' },
] as const;

setup('seed database and authenticate all roles', async ({ page }) => {
  // 1. Seed deterministic test data
  console.log('Seeding database...');
  execSync('npm run db:seed', { stdio: 'inherit' });

  // 2. Log in as each role, save session, clear cookies before next
  for (const user of USERS) {
    // Clear any leftover session from a previous iteration
    await page.context().clearCookies();

    await page.goto('/login');
    await page.fill('#email', user.email);
    await page.fill('#password', user.password);
    await page.click('button[type="submit"]');

    // Wait until the dashboard is reached — confirms login succeeded
    await page.waitForURL('/dashboard/issue-logging', { timeout: 15_000 });

    const stateFile = path.join(AUTH_DIR, `${user.role}.json`);
    await page.context().storageState({ path: stateFile });
    console.log(`  ✓ Saved session for ${user.role} → ${stateFile}`);
  }
});
```

## Troubleshooting

| Symptom | Likely cause | Fix |
|---------|-------------|-----|
| `auth.setup.ts` login fails | Dev server not running or DB not seeded | Run `npm run dev` first; check `npm run db:seed` manually |
| `e2e/.auth/*.json` missing | Setup project skipped | Run `npx playwright test --project=setup` standalone |
| `Cannot find module '@playwright/test'` | Not installed | Run `npm install --save-dev @playwright/test` |
| Selector not found | UI changed since plan written | Run `npx playwright test --headed` to observe, inspect page HTML |
| KB feedback button selector wrong | Detail page not yet read | Run `grep -n "Helpful\|helpful" app/dashboard/kb/\[id\]/page.tsx` |
| Agent fullName mismatch in assign test | Seed value differs | Run `grep -A3 'agent1@' lib/db/seed.ts` and update selector |
| Deactivate button not found | All seeded users already deactivated | Re-run `npm run db:seed` to reset |
